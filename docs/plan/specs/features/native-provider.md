# Native Anthropic Messages subset

Reference OpenCode pin remains v1.19.5 commit
810c0eba1a7348036f8bdf61e6632d0c36c6876c. Relevant full-source paths are
packages/llm/src/providers/anthropic.ts, protocols/anthropic-messages.ts and
provider-error.ts, plus legacy provider SDK registration. The original Go codec
uses a bounded text/client-tool subset, verified through independent loopback
fixtures. No upstream implementation or prompt was copied.

Official current streaming reference:
https://platform.claude.com/docs/en/build-with-claude/streaming.
Its message/block/delta/stop lifecycle, cumulative usage and fragmented tool JSON
were checked against the pinned source and original fixtures. Protocol support
is explicit rather than inferred from model names.

## Working interface

Config.protocol and model profiles accept chat_completions (default) or
anthropic_messages. CLI --protocol and HARNESS_PROTOCOL follow existing
profile/environment/CLI precedence. Endpoint is the exact API URL; no /messages
suffix or provider host is guessed. Native requests send model/max_tokens/stream,
top-level initial system text, user/assistant block histories, input_schema tools,
and tool_use/tool_result pairs. Consecutive roles/results merge appropriately;
orphan, unresolved and duplicate call/result identities fail before HTTP.

Native uses x-api-key and anthropic-version2023-06-01, with no Bearer header.
Default key variable is ANTHROPIC_API_KEY for native and OPENAI_API_KEY for chat;
api_key_env overrides it. Switching protocol in a profile clears an inherited
credential-variable override unless that profile explicitly sets one. No actual
key is persisted in profile/session configuration. Explicit environment overlays
remain authoritative. Redirects are refused for both protocols so selected
prompts/credentials cannot follow a redirect elsewhere. Endpoint error diagnostics
and remote error bodies are not reflected into journals.

HTTP status errors have bounded typed categories authentication/request/timeout/
request_too_large/rate_limit/server/redirect_refused. Transport/408/429/5xx failures
may retry up to three total attempts before a successful stream; bounded backoff
honors cancellation. Once a200 stream begins, it is never replayed automatically,
including partial tool JSON. Completion requires the proper native message_stop
and a recognized finish; length/refusal become length/content_filter errors.
Unsupported pause-turn continuation, reasoning/signature blocks, media, citations,
server-executed tools, OAuth/cloud SDKs and model catalogs are explicitly outside
this subset. Unknown top-level event kinds are forward-compatible; unknown
semantic content blocks are refused rather than silently discarded.

Limits:16MiB request/stream,2MiB event/line,128 blocks/tools,1MiB text/per-tool JSON,
2048 history messages,512-byte call IDs and128-character native tool names. Schema
serialization preflight is bounded and does not dereference remote resources.
UTF8/unpaired Unicode escapes, duplicate IDs, invalid block order and incomplete
streams are rejected. Cumulative input/output/cache counts normalize into existing
usage fields. Model text deltas can render while streaming, but no tool call is
committed/executed until the complete parsed reply succeeds.

## Actual pinned reference observations

Original research/native-provider-reference-model.mjs served /v1/messages on
loopback with dummy credentials. Captures:

- native-provider-reference-complete-evidence.json:
  ev_48cd257a5ebf3d33e64b2349eb09924005b10f60254142fd453fd11863bce860.
- native-provider-reference-drop-evidence.json:
  ev_7c151b370ef27de9616dc87c68cb4cd50efdb0ad0304b750b3af52fd4651874a.

Both requests show x-api-key/version and no Authorization; initial system blocks
are separate from user/assistant history. Fragmented JSON generated one read,
followed by a user tool_result bound to native-read-call, then complete Unicode
text. Observed tool-step tokens are input11/output7; final input11/output9.
SDK beta/cache annotations are extra reference behavior, not Go subset claims.
A separate no-tools request can be generated by the reference for session metadata.

The dropped input-JSON fixture reports an interrupted read error, then continues
to a final text step and exits0 in the observed reference. Go deliberately fails
its run once and executes no incomplete call. This is a failure-policy difference,
not matched lifecycle behavior. Captures have normalized_result.truncated=true
from incomplete shutdown process sampling; owned groups were verified and
fixture listener18790 stopped. This is not network tracing or live account/API
acceptance. Executable identity is prelaunch sampling rather than atomic binding.

## Go and integration verification

research/evidence/harvest-batch-driver.json identifies actual Go captures for
native read/results/text, mixed-protocol typed child, invalid output, compaction
role, partial stream,401 and redirect refusal. Controlled assertions are retained
in harvest-semantic-checks.json. compare_native_provider.py checks saved reference
headers/states and declared Go differences, emitting native-provider-comparison.json.
These are original selected projections, not canonical REA equivalence.

Tests independently frame fragmented SSE, usage/cache counts, strict lifecycle,
unsupported content, JSON bounds/surrogates and cancellation; HTTP tests cover
redaction, retry/backoff, unknown protocol and redirect destination non-contact.
A real runtime integration routes a Chat Completions parent to a native child,
returns file-read evidence as validated JSON, and checks each protocol's separate
headers. Partial-native tool streams create no file and are not retried. Tests
use only controlled endpoints; native live-model/provider parity remains open.
